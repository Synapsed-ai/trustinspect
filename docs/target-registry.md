# Target Registry

TrustInspect supports three target registries:

```text
targets/builtin/   built-in target definitions shipped with TrustInspect
targets/local/     locally calibrated targets created by the tester
targets/disabled/  archived targets hidden from the launcher
```

## Built-in targets

Built-in targets should be stable definitions maintained by the project.

Recommended statuses:

```text
ready
selector_required
experimental
disabled
```

Only targets with stable selectors should be marked `ready`.

## Local targets

Local targets are generated by the calibration wizard and should not be committed by default.

They are ignored by `.gitignore`:

```text
targets/local/*.yaml
```

## Disabled targets

Disabled targets are archived in:

```text
targets/disabled/
```

They are not removed permanently and can be restored.

## Minimal target schema

```yaml
id: promptairlines
name: PromptAirlines
url: https://promptairlines.com/?utm_source=trustinspect
type: web-ui
status: ready
category: public_ai_challenge
input_selector: "#chatInput"
output_selector: "#chat-content .bot-message p"
send_selector: null
frame_selector: null
risk_focus:
  - prompt_manipulation
  - hidden_instruction_following
notes: Public AI security challenge target. Selectors may change.
```
