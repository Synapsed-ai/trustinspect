## Maintainer confirmation: full LLM prompt corpus

On 16 October 2026, Matteo Meucci confirmed that the prompts in `OWASP-TOP-10-LLM-2025.zip` were generated by Synapsed for TrustInspect. This records the maintainer's statement of origin; it is not a claim of independent authorship verification.

The ZIP filename is retained in the catalog as an import reference. It must not be presented as evidence that OWASP authored, supplied or endorsed those prompts. OWASP LLM Top 10 references describe the taxonomy used to organize and map the tests. The previously unanswered question about the origin of this named prompt corpus is closed on the basis of the maintainer's confirmation.

This confirmation concerns the prompts in that archive. It does not silently extend to unrelated suites, copied documentation, dependency licenses, contributor agreements or media permissions. No payload, mapping, catalog title or license is changed by this documentation update.
