# First-alpha publication checklist

The repository is already public. This checklist governs a versioned release, not a first `git init`. All modifications go through review; no broad cleanup script or history rewrite is part of this checklist.

## Required technical gates on the release candidate

- Confirm the exact candidate commit and tree; preserve the approved README, videos, positioning and gallery.
- Pass Security and Release Guards, Installed Distribution, and Local Browser Regression on that candidate.
- Pass Release Dependency Audit in its five recorded OS/Python environments. Inspect actual JSON reports, not only a green job badge.
- Inspect Reachable History Secret Review: full fetched history, refs/count recorded, every signal reviewed without broad exclusions.
- Retain exact runtime/hash locks, build/test environment lists, SBOM, dependency graph, artifact hashes, test logs and commit identity in durable release evidence storage.
- Review any new findings and rerun affected gates after changes. Do not label expired/earlier runs as new validation.

## Ownership and operational gates

- Complete the outstanding decisions in [provenance review](release/provenance-review.md). The maintainer confirmed on 16 October 2026 that the prompts in `OWASP-TOP-10-LLM-2025.zip` were generated by Synapsed for TrustInspect; the origin question for that named corpus is closed. Other materials and third-party notices retain their separately recorded review status.
- The maintainer selected `security@synapsed.ai` on 16 October 2026; the address is documented in SECURITY.md. Before merge/publication, ensure the alias exists, routes to a monitored mailbox and receives an external test message. Selection of the address and editing documentation do not create or test the alias. No mail administration or test delivery was performed by this repository update.
- Verify the three retained video links and playback. The two approved image label edits must not alter counters or classifications.
- Confirm the scope and limitations in the release notes. API, native RAG trace and agent trace adapters are not included in this alpha.

## Human-controlled publication

Review the final diff and explicitly approve merge. After merge, verify the post-merge candidate again and identify which recorded artifacts belong to that exact tree. Agree the package version and matching tag before creating either. Prepare release notes and an artifact checksum manifest; publish only with explicit maintainer approval. Do not upload to PyPI, announce a stable release, enable auto-merge or rewrite history as a side effect.

Current package version: `0.3.0a0`. CI candidate wheels and archives are review artifacts, not published releases. Passing technical gates does not certify model safety, complete detection accuracy, or rights to third-party content.
