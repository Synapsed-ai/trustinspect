# TrustInspect v0.3-alpha Release Readiness

## Release goal

Publish an early open-source release of TrustInspect as an evidence-based Trustworthy AI testing workbench for LLM and agentic applications.

## Release scope

Included:

- Selenium Web UI scanner;
- interactive launcher;
- target registry and calibration workflow;
- OWASP LLM Top 10 2025 light/full suites;
- OWASP AITG light/full suites;
- TrustInspect baseline suite;
- deterministic dynamic test generation;
- dynamic tests per static test;
- evidence-based HTML reporting;
- local vulnerable/hardened demo chatbot.

Not included yet:

- API scanner;
- RAG/vector DB adapters;
- agent trace adapters;
- full Dockerized deployment;
- CI-native JSON/SARIF outputs;
- guaranteed stable selectors for third-party challenge targets.

## Public messaging

Use:

> Evidence-Based Trustworthy AI Testing for LLM and Agentic Applications

Avoid positioning as:

- web security scanner;
- generic DAST;
- Burp/ZAP alternative;
- complete model benchmark.
